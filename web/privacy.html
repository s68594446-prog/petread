数据说明

发布前版本 · 2026-11-06 · 授权版本 openai-media-2026-11-06

你分享什么

只有主动选中的图片、视频、音频，以及填写的宠物物种、场景和观察描述会被上传用于分析。请勿上传未获同意的人脸、声音、地址或其他隐私。照片在发送给模型前去除 EXIF 并缩放；视频使用抽帧及转码音轨。不会读取整个相册、联系人或定位。

谁处理内容

素材先到 PetRead 后端，再发送给 OpenAI API。视频可能使用一次音频分析和一次图像联合分析。你必须在上传前明确同意。撤回授权会阻止新的分析，但不能收回已经发出的请求。OpenAI 的数据处理及可能的安全日志留存取决于其政策与项目设置；store:false 不代表零留存。参阅 OpenAI API 数据控制说明。

PetRead 保存多久

上传原件在任务结束时删除。进程突然崩溃可能留下孤立文件，需要运维清理。分析记录、描述、反馈、任务状态和设备档案保存至主动删除。匿名设备凭证有效期为一年，后端只存其哈希。使用额度计数最多保留两个计数窗口（启动时清理），不包含素材。无广告或第三方浏览追踪脚本。

你的选择

在“隐私与设置”可以撤回授权、导出 JSON、删除当前设备全部数据。删除不可撤销；运行中的任务需先完成。凭证保存在 HttpOnly 浏览器 Cookie 或 iOS 钥匙串中。没有跨设备账号；清除凭证可能失去记录访问权。旧版自报设备 ID 不会自动转为新凭证，避免他人认领历史。

限制和发布状态

AI 结果不是情绪真值、健康诊断或安全保证。本版本仍处发布前验证阶段，尚未正式提交 App Store。正式发布前必须补齐运营主体、联系地址/邮箱、部署地区、服务商合同、备份保留政策和适用地区的隐私文本。当前说明是产品实际数据流说明，不替代完整法律政策。请查看 支持信息；紧急健康问题请联系兽医。
